# Borrower User Guide

## Getting Started

### Prerequisites
1. Phantom or Solflare wallet
2. USDC tokens for loan payments
3. Verified property documentation

### Wallet Setup
1. Install Phantom or Solflare browser extension
2. Create or import your wallet
3. Transfer USDC to your wallet (for mainnet)
4. Request airdrop on devnet: `solana airdrop 1000 USDC_ADDRESS`

## Creating a Loan Application

### Step 1: Register Property
1. Navigate to Properties → Add Property
2. Fill in property details:
   - Property address
   - Property type (Commercial, Office, Retail, etc.)
   - Appraised value
   - Square footage
3. Upload supporting documents
4. Submit for verification

### Step 2: Apply for Loan
1. Go to Loans → New Application
2. Select your verified property
3. Enter loan details:
   - Requested amount (up to 90% LTV)
   - Desired term (12-360 months)
   - Interest rate preference
4. Review loan calculator
5. Submit application

### Step 3: Monitor Application
- View application status in Dashboard
- Await admin approval (typically 1-3 business days)
- Address any additional documentation requests

## Making Payments

### Payment Options
1. Navigate to Payments → Make Payment
2. Select loan from dropdown
3. Enter payment amount or select "Pay in Full"
4. Review payment breakdown (principal vs interest)
5. Connect wallet and sign transaction
6. Confirm payment

### Payment Schedule
- Monthly payments due on the same day each month
- 15-day grace period before late fees
- Payments automatically split between principal and interest

## Viewing Loan Details

### Dashboard
- Current loan balance
- Payment history
- Amortization schedule
- Property information
- Next payment due date

### Amortization Schedule
Access detailed payment breakdown:
- Each payment's principal vs interest portion
- Remaining balance after each payment
- Total interest paid to date
