# Admin User Guide

## Dashboard Overview

### Key Metrics
- Total loan volume
- Active loans count
- Pending applications
- Default rate
- Platform revenue

### Quick Actions
- Review pending applications
- Access borrower KYC
- View property verifications
- Monitor system health

## Managing Loan Applications

### Review Process
1. Navigate to Loans → Pending
2. Click application to view details
3. Review:
   - Property documentation
   - Borrower KYC status
   - LTV calculation
   - Risk assessment
4. Approve or reject with reason

### Approval Criteria
- Property verified: Yes
- Borrower KYC: Approved
- LTV: ≤ 90%
- Risk score: ≥ 500
- Documentation: Complete

## Borrower Management

### KYC Verification
1. Go to Borrowers list
2. Review pending KYC submissions
3. Verify identity documents
4. Approve or request additional info
5. Update KYC status

### Risk Score Updates
Risk scores can be adjusted based on:
- Payment history
- Loan performance
- External credit data
- Market conditions

## Platform Configuration

### Adjustable Parameters
- Maximum LTV (default: 90%)
- Interest rate range (4% - 15%)
- Origination fee (default: 0.5%)
- Servicing fee (default: 0.25%)
- Grace period (default: 15 days)
- Late fee rate (default: 0.5%)

### Emergency Controls
- Pause platform (stops new loans)
- Modify fee structures
- Adjust risk parameters
- Emergency loan modifications

## Reports and Analytics

### Available Reports
- Loan portfolio summary
- Borrower performance
- Payment collection rates
- Default analysis
- Revenue breakdown

### Export Options
- CSV export
- PDF reports
- Scheduled email reports
