# Lender User Guide

## Getting Started

### Prerequisites
1. Phantom or Solflare wallet
2. USDC tokens for funding loans
3. Institutional verification (if applicable)

### Wallet Setup
1. Install wallet extension
2. Create/import wallet
3. Transfer USDC for lending capital

## Finding Loans to Fund

### Browse Available Loans
1. Navigate to Loans → Available
2. Filter by:
   - LTV ratio
   - Property type
   - Loan amount
   - Interest rate
3. Review loan details:
   - Property valuation
   - Borrower risk score
   - Loan-to-value ratio
   - Property location

### Due Diligence
Before funding:
- Review property appraisal documents
- Check borrower KYC status
- Analyze risk score
- Verify property insurance
- Review loan term and conditions

## Funding a Loan

### Process
1. Select loan from available listings
2. Review funding terms:
   - Origination fee (0.5%)
   - Expected return
   - Loan term
3. Connect wallet
4. Sign funding transaction
5. Confirm USDC transfer

### Post-Funding
- Loan appears in your portfolio
- Track payments via dashboard
- Receive interest payments automatically

## Portfolio Management

### Dashboard Overview
- Total invested capital
- Outstanding principal
- Interest earned
- Active loans
- Defaulted loans

### Performance Metrics
- Current yield
- Total return
- Default rate
- Weighted average LTV
